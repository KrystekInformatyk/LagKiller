## 🆕 What is Lag Killer - Priority Tool?

Lag Killer is a lightweight Windows application (signed with certificate `kgstudio.pfx`) that lets you manage process priorities for your favorite PC games.  
By tweaking CPU, GPU, and I/O scheduling priorities in the Windows Registry, you can ensure smoother gameplay and better performance. 🚀

3️⃣ Choose your desired CPU / I/O / GPU priority  
4️⃣ Click **Apply** to save settings  
5️⃣ Use **Reset** to remove all applied tweaks

## ❓ FAQ

🔵 **Does this permanently modify my system?**  
🔹 No – all changes are game-specific and can be reset anytime.  

🔵 **Do I need to configure each game manually?**  
🔹 Yes, but the app remembers your last settings for each game.  

🔵 **Does Lag Killer run in the background?**  
🔹 No – it only modifies registry values when you apply them.
